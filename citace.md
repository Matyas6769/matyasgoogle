# Citace a použité zdroje

## Externí zdroje

- Google. **Google Search**. Cílová adresa vyhledávacích formulářů projektu. Dostupné z: <https://www.google.com/search>
- World Wide Web Consortium (W3C). **The Nu Html Checker**. HTML validátor a odznak validace. Dostupné z: <https://validator.w3.org/nu/> a <https://www.w3.org/Icons/valid-html401>
- World Wide Web Consortium (W3C). **CSS Validation Service**. CSS validátor a odznak validace. Dostupné z: <https://jigsaw.w3.org/css-validator/> a <https://jigsaw.w3.org/css-validator/images/vcss>
- Style Solutions for You. **Seasonal Color Analysis: 4 Autumn Seasons**. Inspirace pro podzimní barevné ladění. Dostupné z: <https://stylesolutionsforyou.com/seasonal-color-analysis-4-autumn-seasons>

- „Na všech stránkách projektu budou 2 odkazy na validaci HTML a CSS. Odkazy budou směřovat na validátory: https://validator.w3.org/ a https://jigsaw.w3.org/css-validator/ nastavené tak, aby validovaly kód dané stránky. Přidej to někam dolů do rohu.“

- „Použij tento obrázek jako wallpaper.“ (Obrázek byl přiložen uživatelem.)
